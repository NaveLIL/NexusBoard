# NexusBoard — План разработки

> Кастомный серверный дашборд с авторизацией, шифрованием и разделением доступа.
> Современный центр управления домашней инфраструктурой.

---

## Концепция

NexusBoard — это self-hosted панель управления серверными сервисами с упором на безопасность, визуал и удобство. Каждый пользователь видит только то, к чему имеет доступ. Все чувствительные данные зашифрованы. Интерфейс адаптирован под десктоп и мобильные устройства, с подготовленной базой под будущее Android-приложение.

---

## Стек технологий

| Слой | Технология | Почему |
|------|-----------|--------|
| Backend | Node.js 20 + Express | Асинхронность, экосистема, простой деплой |
| База данных | SQLite (better-sqlite3) | Нет зависимости от внешних СУБД, бэкап = один файл |
| Авторизация | JWT (access + refresh) + bcrypt | Стандарт индустрии, stateless сессии |
| Шифрование | AES-256-GCM (node:crypto) | Военный стандарт шифрования для URL и API-ключей |
| Frontend | HTML/CSS/JS (без фреймворков) | Легковесность, скорость, полный контроль |
| Иконки | Собственный SVG-пак + Material Symbols | Чёткие на любом DPI |
| Контейнер | Docker + docker-compose | Один `docker compose up` для установки |
| Уведомления | ntfy + Telegram Bot API | Пуши о падениях/событиях |
| i18n | JSON-файлы с переводами | RU → EN → HE (будущее) |

## Роли и доступ

| Роль | Описание | Возможности |
|------|----------|------------|
| **SuperAdmin** | Владелец сервера (ты) | Всё: управление пользователями, сервисами, настройками, просмотр логов |
| **Admin** | Помощники | Добавление сервисов, просмотр мониторинга, без управления пользователями |
| **Member** | Команда | Видит назначенные сервисы, без редактирования |
| **Family** | Семья | Видит только медиа-сервисы (Jellyfin, Immich, Nextcloud и т.д.) |
| **Guest** | Гость | Минимальный набор: только публичные сервисы |

Каждый сервис привязывается к ролям — какая роль его видит. Админ конфигурирует через UI.

## Дизайн и UI

### Экран авторизации
- Тёмный фон с размытым градиентом (фиолетово-синий → тёмный)
- Логотип NexusBoard с эффектом свечения неона
- Поле ввода с плавающими лейблами (floating labels)
- Кнопка входа с пульсирующей анимацией
- Частицы / сетка на фоне (легковесные, canvas)
- Shake-анимация при неправильном пароле
- После успешного логина — zoom-in переход в дашборд

### Дашборд (главная)
- Верхняя строка: логотип | поиск | переключатель языка | колокольчик уведомлений | аватар пользователя
- Системный баннер: CPU | RAM | Disk | Uptime | Network — с анимированными кольцевыми графиками
- Сервисы разбиты по категориям (как сейчас, но красивее):
  - Карточки с glassmorphism эффектом (полупрозрачный фон, размытие)
  - Цветной индикатор статуса (зелёный пульс = онлайн, красный = оффлайн)
  - Иконка сервиса + название + описание
  - Hover: карточка приподнимается + подсвечивается
  - Клик: открывает сервис в новой вкладке
- Drag & drop для перестановки карточек (сохраняется в БД per-user)
- Разные layouts: сетка / список / компакт

### Админ-панель
- Управление сервисами: добавить/редактировать/удалить, выбрать иконку, описание, URL, категория, видимость по ролям
- Управление пользователями: создать, роль, сброс пароля, деактивация
- Логи: кто заходил, когда, откуда (IP + User-Agent)
- Настройки: тема, интервал health-чеков, каналы уведомлений

### Цветовая схема
- Основной фон: `#0a0e1a` (глубокий тёмно-синий)
- Карточки: `rgba(15, 23, 42, 0.7)` + backdrop-blur
- Акцент: `#6366f1` (индиго) + `#8b5cf6` (фиолетовый)
- Успех: `#22c55e`
- Ошибка: `#ef4444`
- Текст: `#e2e8f0` (основной), `#94a3b8` (вторичный)

## Безопасность

1. **Пароли**: bcrypt (12 раундов) — не обратимое хеширование
2. **Токены**: JWT с RS256, access (15 мин) + refresh (7 дней), httpOnly cookies
3. **Шифрование БД**: чувствительные fields (URL, API keys) → AES-256-GCM, мастер-ключ из `.env`
4. **Rate limiting**: 5 попыток логина / 15 мин с одного IP, потом lockout
5. **CSRF**: SameSite cookie + optional CSRF-токен
6. **XSS**: Content-Security-Policy заголовки, sanitize всего вывода
7. **Helmet.js**: набор security headers из коробки
8. **Audit log**: каждый логин / действие записывается с IP и таймстемпом
9. **2FA**: TOTP (Google Authenticator) — фаза 2, под флагом

## API Endpoints

### Авторизация
```
POST   /api/auth/login          # { username, password } → { accessToken }
POST   /api/auth/refresh        # refresh cookie → новый accessToken
POST   /api/auth/logout         # invalidate refresh token
GET    /api/auth/me             # текущий пользователь
```

### Сервисы
```
GET    /api/services            # список сервисов (filtered by role)
POST   /api/services            # создать (admin+)
PUT    /api/services/:id        # обновить (admin+)
DELETE /api/services/:id        # удалить (superadmin)
PATCH  /api/services/:id/order  # изменить порядок (per-user)
```

### Мониторинг
```
GET    /api/health              # статусы всех сервисов
GET    /api/system              # CPU, RAM, disk, uptime, network
GET    /api/docker/containers   # список Docker-контейнеров
```

### Пользователи (superadmin)
```
GET    /api/users               # список пользователей
POST   /api/users               # создать
PUT    /api/users/:id           # обновить роль/данные
DELETE /api/users/:id           # удалить
```

### Настройки
```
GET    /api/settings            # текущие настройки
PUT    /api/settings            # обновить
GET    /api/audit               # лог действий (admin+)
```

## Установка (превью для INSTALL.md)

```bash
# 1. Клонировать репо
git clone https://github.com/NaveLIL/NexusBoard.git
cd NexusBoard

# 2. Скопировать конфиг
cp .env.example .env
# отредактировать .env — задать MASTER_KEY, JWT_SECRET и т.д.

# 3. Запуск через Docker
docker compose up -d

# 4. Открыть в браузере
# http://localhost:3000
# При первом запуске — создание SuperAdmin аккаунта
```
